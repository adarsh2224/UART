# UART Protocol

This project focuses on the Design and verification of the UART (Universal Asynchronous Receiver Transmitter) protocol using Verilog and SystemVerilog.

## contents
* UART_TX --> Master or Transmitter(Sends Data)
* UART_RX --> Slave or Receiver(Receives Data)
* TEST --> Test Bench

## Language Used
* System Verilog
* Verilog

## Tools Used
EDA Playground

## About UART
* UART (Universal Asynchronous Receiver Transmitter) is a serial communication protocol used for transmitting and receiving data between devices.It is called asynchronous because it does not use a separate clock signal for communication.Instead, both transmitter and receiver operate using a predefined baud rate.
